## 🎯 A Visão

O **Lyrien Native Engineering** não é apenas um prompt comum. Trata-se de um **blueprint de Skill** rigorosamente desenhado para forjar um assistente de programação de elite, especializado em desenvolvimento nativo e engenharia de software de baixo nível. 

Nossa arquitetura de IA é baseada em princípios rígidos para garantir resultados de nível de produção:

*   🛡️ **Código Confiável**
*   🚫 **Menos Alucinações**
*   🔍 **Análise de Erros Cirúrgica**
*   ⚙️ **Debug Estruturado**
*   ✅ **Validação de Build**
*   📐 **Engenharia Limpa**

## 🛠️ Arsenal Tecnológico

A Skill gerada possui um contexto profundo e especializado nas seguintes tecnologias e domínios:

### 💻 Linguagens & Runtimes
*   `C` / `C++` (Moderno, RAII, Templates, STL)
*   `C#` (.NET, Async/Await, Span, Memory, Interop)
*   `Lua` / `LuaJIT` (Metatables, scripts, performance)
*   `Cheat Engine Lua` (Trainers, Memory Records, automação)

### 🖥️ Sistemas & Internals
*   `Windows Internals`
*   `WinAPI`
*   `Formato PE`
*   Desenvolvimento e conceitos de drivers

### 🔒 Segurança & Performance
*   `Debugging Avançado` (Logs, debuggers, tracing, profilers)
*   `Otimização de Performance`
*   `Segurança de Código` (Prevenção de Undefined Behavior, análise de vulnerabilidades)

## ⚙️ Áreas de Conhecimento

### C
Programação de baixo nível: memória, ponteiros, undefined behavior, alocadores, segurança.

### C++
C++ moderno: RAII, templates, STL, performance, concorrência.

### C#
.NET: async/await, Span, Memory, interop, runtime.

### Lua / LuaJIT
Metatables, scripts, integração nativa, performance.

### Cheat Engine Lua
Trainers, Memory Records, eventos, automação.

### Windows
WinAPI, processos, threads, memória, PE, conceitos de drivers.
